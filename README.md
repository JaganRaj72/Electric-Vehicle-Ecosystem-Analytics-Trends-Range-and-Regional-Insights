# ⚡ Electric Vehicle Ecosystem Analytics: Trends, Range, and Regional Insights

A comprehensive Data Analytics project that explores Electric Vehicle (EV) adoption trends, manufacturer performance, electric range, Clean Alternative Fuel Vehicle (CAFV) eligibility, and regional distribution. The project combines Python for data analysis and Power BI for interactive dashboard development to generate actionable business insights.

---

## 📌 Project Overview

The Electric Vehicle (EV) industry is rapidly expanding worldwide, making it essential to analyze vehicle adoption, technological advancements, and market trends. This project performs end-to-end data analysis on EV population data to uncover patterns in vehicle registrations, electric range, manufacturer dominance, and geographic distribution.

The project includes:

- Data Cleaning and Preprocessing using Python
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Insights Generation
- Interactive Power BI Dashboard

---

## 🎯 Project Objectives

- Analyze Electric Vehicle adoption trends over the years.
- Identify leading EV manufacturers and models.
- Compare Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
- Evaluate Electric Range across different vehicle brands.
- Analyze Clean Alternative Fuel Vehicle (CAFV) eligibility.
- Explore regional EV distribution by cities, counties, and states.
- Build an interactive dashboard for business decision-making.

## 📈 Key Insights

- Tesla dominates the EV market with the highest number of registered vehicles.
- Battery Electric Vehicles (BEVs) account for the majority of total EV registrations.
- EV adoption has grown significantly after 2020.
- Several premium brands offer the highest average electric range.
- CAFV eligibility varies depending on battery range and vehicle specifications.
- EV registrations are concentrated in major urban regions.
